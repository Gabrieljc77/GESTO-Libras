Nossa ideia de site é criar um site em que ajude tantos pessoas sem surdez e tanto pessoas surdas o aprendizado de libras. O site vai conter o uso de HTML 5, CSS 3 e Javascript em sua criação, suas 2 interações com o usuário  são no jogo que seria um jogo onde a pessoa tenta adivinhar uma palavra e as “letras” seriam sinais de libras para ela tentar adivinhar, ela tem 5 tentativas, se errar todas, perdeu. E a outra interação é um tutorial onde a pessoa pode aprender letra por letra em sinal de libras. O CSS é usado mais para enfeitar o site e tentar deixar ele num tamanho ideal para o usuário não se complicar em seu uso. E tivemos a ideia desse site pois percebemos que uma boa ação nunca é demais, sempre é boa incentivar as pessoas a aprenderem algo novo e sair de sua bolha ideológica. Então decidimos criar a “INOVA” para mudar isso.
